Setup Guide

  1. Spreadsheet URL: pasted above, gives live (view-only) data from your sheet.
  2. To add / edit / delete: open your Google Sheet > Extensions > Apps Script.
  3. Replace the default code with appsscript/Code.gs and save.
  4. Deploy > New deployment > Web app.
  5. Execute as Me, access Anyone, then Deploy.
  6. Copy the /exec URL into the Apps Script field and tap Test Connection.
  7. Purpose / PIC / Status options load from the sheet's live dropdowns.
